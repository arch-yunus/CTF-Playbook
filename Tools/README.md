# The Arsenal (Tools)

This directory contains custom scripts, automation tools, and configuration files.

## Categories

### 1. Web
- `dirsearch-config/`: Custom wordlists and settings for dirsearch.

### 2. Pwn/Rev
- `exploit-templates/`: Standard pwntools templates.
- `gdb-init/`: Custom .gdbinit files.

### 3. General
- `recon-automation.sh`: Script to automate initial nmap and subdomain scans.
